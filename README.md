# 🚀 NEXUS — Stock Trading Platform

> A futuristic JavaFX trading simulator for market discovery, buying and selling stocks, portfolio tracking, and performance analytics.

## ✨ Features
- 📈 Market dashboard with simulated price movement
- 💹 Buy and sell paper trades
- 💼 Portfolio holdings and allocation
- 💰 Cash balance, valuation, profit/loss and return
- 🧾 Transaction history
- 🔎 Market search
- 📉 Price-history chart
- 👤 Paper trading account
- 🎨 Modern animated dark trading interface

## 🛠️ Technology Stack
- Java 21
- JavaFX 21
- Maven
- Object-Oriented Programming
- ArrayList / LinkedHashMap
- JavaFX Charts
- CSS

## 🚀 Run
```bash
git clone https://github.com/HenryDanielP/CodeAlpha_StockTradingPlatform.git
cd CodeAlpha_StockTradingPlatform
mvn clean javafx:run
```
